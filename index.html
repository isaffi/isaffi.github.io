Threads Buzz Finder

個人用の SNS 発信サポートツール

このツールについて

Threads Buzz Finder は、運営者が自分の Threads（スレッズ）での発信を改善するために、個人のパソコン上で使っているツールです。 一般の方に公開・提供しているサービスではありません。

  • 運営者自身の Threads 投稿の表示回数などを記録し、伸び方を確認します（Threads 公式 API を使用）。
  • 発信の参考にする投稿を整理し、紹介する商品を楽天市場の公式 API（楽天ウェブサービス）で検索します。
  • 投稿の構成を考える補助に、AI（Anthropic 社の Claude API）を使います。

プライバシーポリシー

本ツールは運営者本人のみが使用し、第三者の利用者を想定していません。取り扱う情報と方針は次のとおりです。

  1. 取得する情報：運営者本人の Threads アカウントの投稿と、その表示回数などの数値。公式 API で取得できる範囲の公開投稿。楽天市場の商品情報（商品名・価格・評価など）。
  2. 利用目的：運営者本人の SNS 発信の改善（投稿内容の検討、紹介する商品の選定）のためだけに利用します。
  3. 保存場所：取得した情報は運営者のパソコン内にのみ保存し、外部のサーバーには保存しません。
  4. 第三者への提供：取得した情報を販売・公開・第三者へ提供することはありません。投稿の構成を考える補助のため、投稿の本文を Anthropic 社の Claude API に送信することがあります。
  5. 保存期間と削除：検索結果の記録は最大 90 日で自動的に削除します。運営者はいつでもすべてのデータを削除できます。
  6. お問い合わせ：本ツールに関するお問い合わせは、運営者の Threads アカウント（@rak.ukaji）までご連絡ください。
